# Yousaf Zeb - Personal Portfolio

Live: https://yousafzeb.vercel.app

Personal portfolio website built with Next.js, TypeScript, and Tailwind CSS.

## Tech Stack

- Framework: Next.js 16 (App Router)
- Language: TypeScript
- Styling: Tailwind CSS v4
- Animations: CSS keyframes + IntersectionObserver
- Deployment: Vercel

## Highlights

- Responsive single-page portfolio with smooth section navigation
- Typewriter hero intro and floating visual effects
- Scroll reveal animations and scroll progress indicator
- Project cards linked directly to GitHub repositories
- Contact section with Gmail compose, LinkedIn, and GitHub links
